# Charles’ Work and Experiments

Public home: https://charlesdclarke.github.io/

A plain HTML/CSS website hosted on GitHub Pages. No build tools, subscriptions, database or paid domain are needed. Hosting uses the public repository `charlesdclarke/charlesdclarke.github.io`, with Pages set to deploy from `main`, `/ (root)`.

## Add another project

1. Publish the new project and copy its public URL.
2. In `index.html`, copy the `<article class="project">` block inside the collection section. Replace its title, copy, image, tags and links.
3. Add a link inside `<div class="menu-panel">` using the same project URL and title.
4. Update `01 / A GROWING COLLECTION` to the new project count. Remove or adapt the closing note if appropriate.
5. Upload the updated files to this repository and commit them. GitHub Pages publishes the update automatically.

Only add work intended for public viewing. This site contains no analytics, advertising, or visitor accounts; GitHub Pages logs IP addresses for security. See https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages.

Columbus remains independently hosted at https://charlesdclarke.github.io/columbus-voyages/.

The menu uses native HTML details and works without JavaScript. `menu.js` adds outside-click and Escape-key dismissal. Artwork reuses the ship design from Across an Ocean.
